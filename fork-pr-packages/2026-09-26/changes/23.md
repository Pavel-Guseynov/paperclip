## Review outcome

Problem: Named gateway tool discovery evaluates the entire company tool catalog and issues uncached queries per candidate, leading to 30s latency timeouts and agent profile tool leakage.

Implementation: Evaluates only candidates permitted by the gateway profile; treats `tool_mcp_gateways.profile_id` as authoritative; caches and bounds policy queries per discovery call.

## Regression and touched-line verification

- Regression tests (`server/src/__tests__/scope-named-gateway-tool-discovery.test.ts`):

  2) `a runtime gateway with profile_id and no binding row lists only its profile's tools, never the agent's`: fails on base (falls back to agent profile), passes on head.
  3) `one tools/list issues a bounded number of policy-context queries, independent of the company's tool count`: fails on base (109 queries > 15), passes on head.
