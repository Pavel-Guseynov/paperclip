# feat(review): key review admission by repository revision

Unsent discussion draft. The operator must decide whether and where to post it.

**Problem**

Repeated review requests for one revision can launch repeated external review work.

**Proposed outcome**

Persist a revision identity and review decision record.

**Existing work and scope**

Upstream PR 13717 already provides typed GitHub review tools, but not this admission contract. Depends on 09 and needs core-work coordination before opening.

**Decision needed before a PR**

Implementation is best-effort bookkeeping; requested durable admission and exactly-one invocation are absent.

**Acceptance still required**

Requires actual admission before launch, one invocation under controlled concurrency, restart-safe pending claims, and immutable decision reuse. A unique ledger row does not prove those outcomes.

**Compatibility concerns**

The caller creates a review before admission, ignores duplicate refusal and swallows ledger errors. Missing identity is allowed; finished identity opens a new round.
